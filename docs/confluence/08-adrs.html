Architecture decision records

ADR 0001 — Neo4j for the lineage graph

Status

Accepted for this portfolio. The vocabulary stays OWL.

Context

Recall and trace are path questions. BLE-0457 becomes FAR-118 and then BIS-031.

Decision

Project the ERP extract into a property graph. Uniqueness constraints on id. Derived INPUT_OF edges for variable-length walks. OWL file remains the versioned vocabulary, not the instance store.

Consequences

Cypher is readable for the hero query. Instance data is loaded by Python, so a Neo4j-only rule engine is future work. CI uses the same lineage functions in memory.

ADR 0002 — LangGraph for the workflow

Status

Accepted.

Context

A recall must pause for a person. A single prompt cannot hold that pause.

Decision

LangGraph StateGraph with a supervisor and specialist nodes. MemorySaver checkpoints the thread. interrupt runs after the proposal is written and before “Recall issued”.

LangChain is limited to prompt templates.

Consequences

The route in mock mode is keywords, so tests are stable. The checkpointer is in-process only.

ADR 0003 — MCP tools and a minimal A2A card

Status

Accepted as a teaching surface.

Context

Other assistants should call trace and certificate checks without scraping the UI. A second agent should be able to discover this one.

Decision

MCP tools: trace_lot, check_certificates, search_documents. Separately, publish /.well-known/agent-card.json with protocol: a2a-minimal-0.1 and accept POST /a2a/tasks. The card says it is not a full A2A stack.

Consequences

Two protocols, clearly scoped. A complete A2A task model is not implemented.

ADR 0004 — Hybrid retrieval

Status

Accepted.

Context

“What is upstream of BIS-031?” is a graph fact. “What did the mill audit say?” is prose.

Decision

Deterministic walks for lineage and certificates. Vector search for chunks linked to those nodes. Text-to-Cypher is an extra read path with a validator, not the only path.

Consequences

Answers for the hero chain do not depend on embedding quality. Free-form Cypher is limited to known templates in memory mode and to any guarded read on Neo4j.

ADR 0005 — Mock LLM as the default gateway

Status

Accepted.

Context

The repo must run in CI and on a laptop with no API key, and must not invent lot ids.

Decision

LLM_MODE=mock by default. The mock returns a fixed sentence. LLM_MODE=openai posts to an OpenAI-compatible /chat/completions. Narratives that contain unknown ids are dropped. AGRITRACE_AS_OF=2026-11-13 freezes certificate expiry.

Consequences

Eval measures tools, not a hosted model. Switching dimension of embeddings requires a new vector index.

ADR 0006 — SQL stays the system of record

Status

Accepted.

Context

Lots and shipments are born in an ERP. A graph is a projection for questions.

Decision

Model an ERP schema and round-trip every load through SQLite before the graph. Documents live in SQL too, then become chunks.

Consequences

Postgres is the intended hosted engine; only SQLite is wired. The schema uses portable column types.

ADR 0007 — Human approval and read-only Cypher

Status

Accepted.

Context

A recall recommendation can pull biscuits off a shelf. A generated query must not delete the graph.

Decision

The recall route interrupts until approve or reject. Only the regulator can approve. validate_cypher rejects writes, multiple statements, unknown labels, and large LIMITs. MCP does not expose free Cypher.

Consequences

The demo cannot “just answer” a recall in one call. That is intentional.
